# The World in One Page — 21 November 2026

One image summing up Saturday 21 November 2026's world news: 35 stories
across 6 continents — 11 numbered lead panels, a world map with numbered
pins, a dense ALSO ON list (#12–35), and a sources footer. Every story was
reported on 21 November 2026; disputed claims are attributed.

`main.py` (Python 3.13, PIL only) draws the page deterministically — no
network, no clock, no randomness — and writes `entry.png` (1024×1024,
under 1 MiB) to `$MAKEFUN_OUTPUT_DIR` (default `out/`).

Run it:

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
